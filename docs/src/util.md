# util.jl Documentation

The `util.jl` file provides a suite of utility functions primarily focused on filesystem navigation, project root discovery, and environment verification for the DSO API. These functions are not exported by the DSO.jl module.

---

```@docs
DSO.is_relative_to
DSO.find_in_parent
DSO.get_project_root
DSO.dso_cli_available
DSO.run_dso_cli
DSO.read_safe_yaml
```
